# Reproduction boundary

Check out tag `v0.6.2` and run `python paper/ijar-v32/verify_release.py`.
The release verifies the manuscript-to-artifact map and the count-level
certification boundary. End-to-end model training is not claimed. Licensed or
large source data, checkpoints, and record-level logits are not included.

The fixed-size empirical-reservoir results target the frozen reservoir, not an
unobserved deployment population. The finite-frame results target only their
registered finite frames. Source-disjoint evaluation images do not constitute
independent retraining or prospective confirmation.
