# Reproduction boundary

Check out tag `v0.7.0` and run
`python paper/ijar-v37/verify_release.py`. The verifier reproduces the
manuscript-to-artifact map and registered count-to-decision claims. The public
release does not claim end-to-end model-training reproduction.

The Figure 2 validity denominator is 443 proposal-feasible conditions. Seven
proposal-infeasible reject-all placeholders remain only in the 450-condition
utility roster. The valid clientwise conservative reference protects the same
worst-client target. Pooled fixed-quota calculations remain mechanism
diagnostics rather than full-simplex competitors.

The PACS package retains the complete 30-model roster, 90 procedure decisions,
1,080 candidate decisions, count tensors, outcome gates, independent replay,
completion seal, and exact execution-source identity. The public source tag
`pacs-local-v1-fa016c1` resolves to the execution commit. Licensed input arrays,
pretrained archives, checkpoints, and full training reproduction are excluded.
The rerun used fresh seeds after earlier PACS outcomes were known and is not an
untouched-dataset or source-population replication.
