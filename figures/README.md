# Fed-CORE IJMLC v7 artwork

Figures 1–9 match `FedCORE_IJMLC_Submission_Final_v7.docx`.

- `FigN.eps`: publication vector companion (transparency is flattened where required by EPS).
- `FigN.pdf`: vector PDF with embedded fonts; preferred for viewing and print inspection.
- `FigN.tif`: lossless LZW TIFF, nominal 600 dpi at the listed physical size.
- `FigN.png`: lossless 600 dpi raster inserted into the Word manuscript.
- `FigN.svg`: editable vector companion; font substitution is possible outside the export environment.

The line diagram and plot vectors are available independently of raster resolution. Figure 9 includes nine native 28 × 28-pixel PathMNIST tissue patches; the 600 dpi figure export does not create additional tissue-image detail. These illustrative patches retain the MedMNIST Dataset's CC BY 4.0 terms and the source citations in the manuscript; see [third-party notices](../THIRD_PARTY_NOTICES.md).
